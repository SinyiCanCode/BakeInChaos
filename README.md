🔥 Bake in Chaos

An action RPG where the kitchen is the battlefield — and every dish is a choice between technique and chaos.

✦ Premise

Imagine Vagrant Story colliding with Darkest Dungeon inside a burning restaurant.

Bake in Chaos is a 2D side-scrolling action RPG where you don’t wield swords — you wield frying pans, chef knives, whisks, and heat.

Each class represents one of the eight classical kitchen brigades of Auguste Escoffier, while every enemy is a twisted culinary creation born from the collision between French technique and line-cook madness.

Combat revolves around an original mechanic: the Culinary Sphere + Chain System.

You don’t simply attack — you combine techniques under pressure, assembling sequences the same way a chef builds a dish during service. Miss the timing and the sauce breaks. Execute the chain correctly and you unleash a devastating Finisher that feels equal parts elegance and violence.

✦ The World

A world where cooking evolved into martial art.

Where sentient madeleines rebel against their creators. Where croissants became armored beasts lined with razor-sharp layers of butter. Where a corrupted loin known only as Tenderlion rules over an underground kingdom of meat that refuses to die properly.

The visual and tonal direction draws heavily from the dense gothic atmosphere and mechanical precision of Vagrant Story, fused with the psychological tension and oppressive weight of Darkest Dungeon.

Every decision matters. Every mistake costs something. Style is not decoration — it is part of the gameplay itself.

✦ Classes

Eight brigades. Eight combat philosophies.

Each class changes not only stats, but also pacing, combo structure, risk management, and execution style.

Pâtissier — DEX-oriented. Surgical precision, rapid chains, cold execution.
Rôtisseur — STR-oriented. Heavy pressure, brutal heat-based attacks, aggressive stance control.
(Six more brigades currently in development.)
✦ Current State

The core combat system has been successfully validated.

The Culinary Sphere + Chain System works — and it works well. Everything else is being built around that foundation.

Now comes the long part: content, balance, enemies, atmosphere, and refinement.

✦ Technical Stack
Engine: Godot Engine 4
Language: GDScript
Target Platform: HTML5/Web-first
Environment: Windows + Visual Studio Code

The choice of Godot is deliberate: open-source ecosystem, mature 2D pipeline, and native web deployment.

The web-first approach is strategic. The game should exist first in the frictionless accessibility of the browser before expanding anywhere else.

✦ Development Philosophy

Bake in Chaos has no deadline.

There is no “Q3 2026 release window” here. No public milestone roadmap. No countdown timer.

That is intentional.

Bake in Chaos is an author-driven project built at the pace required by the complexity of its systems. Action RPGs with original combat mechanics are difficult to make — and making them well matters more than making them fast.

Development happens alongside professional work and other projects. Every system is validated before expansion. Every class exists only when its design is ready — not because a spreadsheet demands it.

If you came looking for a release date, there isn’t one.

If you came looking to watch something carefully crafted take shape over time — welcome to the kitchen.
